# List of Neural System Simulators

AFAIK: 
1. [NEURON](https://www.neuron.yale.edu/neuron/download) : support both single neurons and networks of neurons
2. [GENESIS](http://genesis-sim.org/GENESIS/)
3. [NEST](https://github.com/nest/nest-simulator): comprehensive toolkits, also support multiple machine simulation

These are the three I plan to explore. And this [comparison](https://grey.colorado.edu/emergent/index.php/Comparison_of_Neural_Network_Simulators) seems to be fairly comprehensive on the software space of simulation.
