# Resources for Implementing Linear Regression Based On Normal Equation

Not understanding, implementing. 
- [Derivation of the Normal Equation for linear regression](https://eli.thegreenplace.net/2014/derivation-of-the-normal-equation-for-linear-regression)
- [Normal Equation and Matrix Calculus](https://eli.thegreenplace.net/2015/the-normal-equation-and-matrix-calculus/)
- [Wikipedia entry on linear least square ](https://en.wikipedia.org/wiki/Linear_least_squares_%28mathematics%29)
- [Matrix calculus Wikipedia page ](https://en.wikipedia.org/wiki/Matrix_calculus#Derivatives_with_vectors) 
        - it's quite messy but readable.
- [Another derivation of the matrix form](https://ayearofai.com/rohan-3-deriving-the-normal-equation-using-matrix-calculus-1a1b16f65dda).

Implementation in C 
- [A practical description of the simple linear regression algorithm (1-variable) and example.](http://www.pgccphy.net/ref/linreg.pdf)
- Here is [one](https://www.geometrictools.com/Documentation/LeastSquaresFitting.pdf), two more dubious sources ([here](http://studentboxoffice.in/jntuh/notes/computer-programming-lab/write-a-c-program-to-implement-the-linear-regression-algorithm/123) and [here](http://c-program-example.com/2011/11/c-program-to-implement-linear-regression-algorithm.html)).
- Perhaps the best resource is GSL, which has probably the best reference on linear regression and its implementation [here](https://www.gnu.org/software/gsl/doc/html/lls.html)
- A practical description of algorithm and example.

(less-related and equally interesting the [non-linear regression description](https://www.gnu.org/software/gsl/doc/html/nls.html).)

Books: 
- Regression by Bingham and Fry
- Matrix Algebra by Abadi and Magnus
