# Prof. Might's "12 resolutions for programmers"

I quoted the headers but you should all go to read the [whole thing](http://matt.might.net/articles/programmers-resolutions/). It makes you a better programmer and a better person.

"  

1. Go analog.
2. Stay healthy.
3. Embrace the uncomfortable.
4. Learn a new programming language.
5. Automate.
6. Learn more mathematics.
7. Focus on security.
8. Back up your data.
9. Learn more theory.
10. Engage the arts and humanities.
11. Learn new software.
12. Complete a personal project.

"
